# Política de Privacidad de ParcelContact

**Última actualización:** 2 de octubre de 2026

## 1. Introducción

ParcelContact es una aplicación diseñada para facilitar la gestión de paquetes y el envío de notificaciones relacionadas con entregas mediante WhatsApp.

Esta Política de Privacidad describe qué información puede procesar ParcelContact, para qué se utiliza, cómo se protege y qué opciones tienen las personas respecto al tratamiento de sus datos.

Al utilizar ParcelContact, el usuario reconoce haber leído esta Política de Privacidad.

## 2. Finalidad de la aplicación

ParcelContact permite analizar etiquetas de paquetería para facilitar la identificación de información necesaria para gestionar una entrega y, cuando corresponda, enviar una notificación mediante WhatsApp Business Platform.

La aplicación está diseñada para ser utilizada dentro de un proceso autorizado de recepción, gestión o entrega de paquetes.

ParcelContact no debe utilizarse para enviar mensajes no solicitados, publicidad no autorizada o comunicaciones a personas que no hayan proporcionado autorización para ser contactadas cuando dicha autorización sea requerida.

## 3. Información procesada

Dependiendo del uso de la aplicación, ParcelContact puede procesar:

- Número de teléfono del destinatario.
- Número o código de rastreo del paquete.
- Empresa de paquetería o transportista.
- Información necesaria para preparar la notificación relacionada con el paquete.
- Información relacionada con el consentimiento para recibir comunicaciones.
- Estado técnico de los mensajes enviados mediante WhatsApp, como enviado, entregado, leído o fallido.
- Información técnica necesaria para prevenir envíos duplicados y gestionar solicitudes de baja.

La aplicación Android podrá utilizar la cámara o una imagen seleccionada por el usuario para analizar etiquetas mediante reconocimiento de texto y lectura de códigos de barras o códigos QR.

## 4. Fotografías y reconocimiento de texto

Las imágenes de las etiquetas se utilizan para identificar información necesaria para el procesamiento del paquete.

El diseño de ParcelContact busca realizar el reconocimiento de texto y códigos en el dispositivo Android.

El backend de ParcelContact no necesita recibir las fotografías de las etiquetas ni el texto OCR completo para realizar el envío de una notificación por WhatsApp.

Antes de solicitar el envío de una notificación, los datos relevantes deben ser revisados y validados.

## 5. Uso del número telefónico

El número telefónico se utiliza exclusivamente para gestionar comunicaciones relacionadas con el paquete o servicio correspondiente.

ParcelContact no está diseñado para vender números telefónicos, crear bases de datos comerciales de destinatarios ni utilizar estos datos para publicidad no autorizada.

El envío mediante WhatsApp está sujeto a las políticas y condiciones aplicables de WhatsApp Business Platform.

## 6. Consentimiento

ParcelContact requiere que exista una base válida para contactar al destinatario y, cuando corresponda, que se haya obtenido su consentimiento para recibir comunicaciones mediante WhatsApp.

El sistema puede registrar información relacionada con la existencia y origen del consentimiento.

El hecho de que un número telefónico aparezca impreso en una etiqueta de envío no se considera, por sí solo, autorización suficiente para utilizarlo con cualquier finalidad.

## 7. WhatsApp Business Platform

ParcelContact utiliza WhatsApp Business Platform para realizar determinadas comunicaciones.

Para efectuar un envío, la información necesaria puede ser transmitida a los servicios de Meta y WhatsApp de acuerdo con sus respectivas políticas y términos.

ParcelContact utiliza la API oficial de WhatsApp Business Platform y no automatiza la interfaz de la aplicación personal de WhatsApp para enviar mensajes.

## 8. Conservación y minimización de datos

ParcelContact está diseñado siguiendo principios de minimización de datos.

El backend puede conservar identificadores derivados mediante técnicas criptográficas para:

- Prevenir envíos duplicados.
- Reconocer consentimientos previamente registrados.
- Respetar solicitudes de baja.
- Mantener la integridad operativa del sistema.

El diseño actual del backend evita almacenar en sus tablas el número telefónico en texto claro, el nombre del destinatario, fotografías de las etiquetas o el contenido completo obtenido mediante OCR.

La información necesaria para gestionar bajas puede conservarse mientras sea necesario para impedir comunicaciones posteriores no autorizadas.

## 9. Solicitudes de baja

Una persona puede solicitar dejar de recibir comunicaciones.

ParcelContact puede reconocer solicitudes de baja realizadas mediante palabras o instrucciones compatibles con el sistema, así como solicitudes registradas por otros medios autorizados.

Una vez registrada una baja, el sistema está diseñado para impedir nuevos envíos que no estén autorizados.

## 10. Seguridad

ParcelContact utiliza medidas técnicas destinadas a proteger la información procesada.

Entre estas medidas se incluyen:

- Comunicación mediante HTTPS.
- Autenticación para acceder a la API.
- Almacenamiento de credenciales únicamente en sistemas de servidor.
- Validación de webhooks.
- Uso de secretos independientes para funciones sensibles.
- Prevención de duplicados.
- Minimización de datos almacenados.

Los tokens de acceso, secretos de Meta y otras credenciales privadas no deben almacenarse dentro de la aplicación Android.

## 11. Compartición de información

ParcelContact no está diseñado para vender información personal.

La información necesaria puede ser procesada por proveedores tecnológicos utilizados para prestar el servicio, incluyendo servicios relacionados con WhatsApp Business Platform, infraestructura de alojamiento y otros proveedores necesarios para la operación del sistema.

Cada proveedor puede estar sujeto a sus propias políticas de privacidad y términos.

## 12. Derechos y solicitudes relacionadas con datos personales

Las personas pueden solicitar información relacionada con el tratamiento de sus datos y, cuando resulte aplicable conforme a la legislación correspondiente, solicitar acceso, rectificación, eliminación, oposición o limitación del tratamiento.

También pueden solicitar dejar de recibir comunicaciones mediante los mecanismos de baja disponibles.

Las solicitudes deberán enviarse utilizando la información de contacto indicada al final de esta política.

## 13. Uso autorizado

ParcelContact está destinado a procesos legítimos de gestión y notificación de paquetes.

No se autoriza su uso para:

- Spam.
- Acoso.
- Mensajes masivos no autorizados.
- Venta de información personal.
- Recopilación de números telefónicos para fines no relacionados con la gestión autorizada del paquete.
- Eludir las políticas de WhatsApp o Meta.

## 14. Servicios de terceros

ParcelContact puede depender de servicios proporcionados por terceros, incluyendo WhatsApp Business Platform y proveedores de infraestructura.

El uso de dichos servicios puede estar sujeto a términos y políticas adicionales proporcionados por esos terceros.

## 15. Cambios a esta Política de Privacidad

Esta Política de Privacidad podrá actualizarse cuando cambien las funciones de ParcelContact, los proveedores utilizados, los requisitos legales o las prácticas de tratamiento de datos.

La fecha de la última actualización se mostrará al inicio del documento.
